# Simple Interest Calculator

## Project Description
This project is a simple interest calculator developed using Bash scripting. It calculates the simple interest based on the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
The calculator accepts three inputs:
- Principal amount
- Annual rate of interest
- Time period (in years)

## Output
The program calculates and displays the simple interest.

## Technologies Used
- Bash Scripting
- Linux Command Line
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the terminal.
3. Navigate to the project directory.
4. Run the following command:

bash simple-interest.sh
